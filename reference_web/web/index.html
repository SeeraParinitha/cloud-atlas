How it works

Try the workspace →
THE PROCESS

A place. An acquisition.
A more useful view.

Start with a real satellite observation. The system combines image processing with nearby observations of the same area to reduce cloud and shadow obstruction.

01

Select an area

Search for a place or draw a box on the map. Choose a date range to discover available Sentinel-2 acquisitions.

02

Verify coverage

Availability masks check that at least 99.5% of the chosen area contains observations. Cloudiness and missing data are checked separately.

03

Process with HSFormer

The network processes RGB tiles. A trained temporal component uses an earlier observation, masks, and reference age to inform reconstruction.

04

Review and compare

Automatic checks screen the result. Move the comparison slider to inspect changes, then download the original or result PNG.

TEMPORAL CONTEXT

Earlier imagery adds information.

The model's prior comes from the preceding 60 days. When reconstruction remains incomplete, the system can use a complete nearby observation of the area as the result.

Cloud-hidden details are estimates; observations from different dates can contain real surface changes.

READING THE RESULTS

Inspect the image, not just its appearance.

Compare roads, shorelines, and visible terrain. Automated cloud and shadow checks can miss haze or other errors.

These results support exploration and research. They do not establish exact ground conditions beneath an opaque cloud on the selected date.
